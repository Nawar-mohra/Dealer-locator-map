# Dealer locator mobile screen

This is a dependency-free implementation of the mobile Scania dealer detail screen.

## Live demo

Open the deployed mobile demo at [https://nawar-mohra.github.io/Dealer-locator-map/](https://nawar-mohra.github.io/Dealer-locator-map/). GitHub Pages deploys updates automatically when changes are pushed to `main`.

## Local preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173). On desktop, the page stays in a centered 402px mobile canvas.
